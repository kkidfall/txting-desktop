# Txting for Mac and Windows

The desktop app for [Txting](https://txting.app): your team's texting inbox in its own window, with notifications for new texts.

## Download

**[Get the latest version](https://github.com/kkidfall/txting-desktop/releases/latest)**

- **Mac:** download the file ending in `-mac.dmg`, open it, and drag Txting into Applications.
- **Windows:** download the file ending in `-windows-setup.exe` and run it.

### First time you open it

- **Mac:** if macOS says it can't check the app, open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**.
- **Windows:** if you see "Windows protected your PC", click **More info → Run anyway**.

Then sign in with your Txting email and password, and allow notifications when asked.

## Good to know

- Notifications arrive while Txting is running. Closing the window keeps it running in the Dock (Mac) or the system tray (Windows); quitting it stops them.
- To have it start with your computer, turn on **Open at Login** in the Txting menu (Mac) or **Start when I sign in to Windows** in the tray icon's menu (Windows).
- Updates install by themselves.
